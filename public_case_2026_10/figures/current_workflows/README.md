# Current manuscript workflow figures

These are the current monochrome Fig. 1 (agent framework) and Fig. 2 (coordinate-union conditional simulation), copied directly from the manuscript figure files. Both are conceptual diagrams; no synthetic or measured values are generated by the drawing scripts.

Rebuild with Python, Matplotlib, PyMuPDF and Pillow:

```text
python -B draw_framework_bw.py
python -B draw_flowchart_bw.py
```

The first writes to `figures/`; the second writes to `flowchart_bw/`. `workflow_layout_bw.py` supplies drawing utilities and is imported by the flowchart script; run the two entry points above. The scripts are unchanged copies of the sources used for the manuscript PDFs. They produce vector PDFs and SVGs plus raster previews; only the two current PDFs are supplied here to avoid duplicate exports. Available fonts can affect new renderings. These scripts make no API calls and run no numerical experiments.
