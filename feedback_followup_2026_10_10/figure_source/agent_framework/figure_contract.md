- Archetype: schematic-led composite; the upper feedback loop is the primary panel, followed by covariance-preserving simulation and separate fixed-reference checks.
- Backend: Python/Matplotlib only, chosen explicitly. Existing figure conventions are reused as style, with a newly composed layout.
- Export: 183 × 145 mm, selectable PDF text, editable SVG text, 600 dpi PNG and PDF-rendered preview. Minimum intended type 8 pt.
- Data: conceptual diagram, no invented numerical results. Stated 20-candidate budget, 4 × 5 versus 5 × 4 batches, two reserve proposals, cached benchmark scores, and full-data-selected reference structures come from the current manuscript methods.
- Integrity: LLM proposes structures, numerical routines fit parameters. Benchmarks query previously fitted shared scores. Neighborhoods are based on visited best candidates; unseen scores are never supplied. Fixed-structure borehole checks are a separate reference branch, not nested agent model discovery.
- Output stays in the revision directory for review; no manuscript sources or existing submission figure files are overwritten.
